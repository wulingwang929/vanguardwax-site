# 品牌色

> 從舊站 logo 與首頁輪播圖取色（2026-09-21）。舊站整體是「黑底＋紅色＋白字」的賽車感風格。

| 角色 | 色碼 | 來源 | 用途建議 |
|---|---|---|---|
| 品牌紅 | `#E60012` | logo 的紅色 V | 主要按鈕、重點標籤、連結 hover。一個畫面只用在最重要的地方 |
| 深黑 | `#0A0A0A` | 輪播圖背景 | 頁首、頁尾、主視覺區的深色底 |
| 炭灰 | `#1C1C1C` | 輪播圖背景的次要層 | 深色區塊裡的卡片底色 |
| 白 | `#FFFFFF` | logo 字樣 | 深色底上的文字、淺色頁面的底色 |
| 淺灰 | `#F4F4F4` | （新增）| 淺色頁面的區塊分隔、表格底色 |
| 內文灰 | `#5A5A5A` | （新增）| 淺色底上的內文與說明文字 |
| 招牌藍（輔助） | `#2E4F8F` | 公司大樓招牌 | 只在需要第二個顏色時少量使用，例如資訊提示 |

## 使用原則
- 以黑、白、灰為主，紅色只當重點色，面積控制在一成以內，才不會顯得廉價。
- 紅字放在黑底上可讀性不足（對比不夠），紅色建議用在按鈕底色（配白字）或粗體標題，不要用在小字內文。
- 招牌藍是公司建築上的顏色，不在 logo 裡，要不要用請你決定。

**注意：logo 只有 563×100 像素**，不到 1000px，放大會糊。網頁頁首夠用，但做大圖或印刷不行。請跟公司要原始向量檔（.ai、.eps、.svg 或 .pdf）；拿不到的話，衝刺日可以請 Claude Code 照著描一個 SVG 版本。
